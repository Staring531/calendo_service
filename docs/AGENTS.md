# AGENTS.md

The root [AGENTS.md](../AGENTS.md) applies here too. On a conflict, this file wins for `docs/`.

## Direction

Documents under `docs/product/` state what is being built and why. They do not raise a
requirement. An issue may quote them. [`rfcs/AGENTS.md`](../rfcs/AGENTS.md) says when an issue
leads to a draft RFC.

Write the documents for a reader who has not seen the code. Prose rules for English and Chinese
are in [`.agents/skills/calendo-dev/reference/writing.md`](../.agents/skills/calendo-dev/reference/writing.md).
