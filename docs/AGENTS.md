# AGENTS.md

The root [AGENTS.md](../AGENTS.md) applies here too. On a conflict, this file wins for `docs/`.

## Direction

Documents under `docs/product/` state what is being built and why. They can supply the wording of
a proposal. Follow the development flow in the root `AGENTS.md` before changing behaviour the
owner has not approved. Open questions there are candidates for RFCs;
[`rfcs/AGENTS.md`](../rfcs/AGENTS.md) says when to draft one.

Write the documents for a reader who has not seen the code. Prose rules for English and Chinese
are in [`.agents/skills/calendo-dev/reference/writing.md`](../.agents/skills/calendo-dev/reference/writing.md).
